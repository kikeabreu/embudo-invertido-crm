# Button
Primary call-to-action. Use for the single most important action on a view.

```jsx
<Button variant="primary" size="md">Start selling</Button>
<Button variant="accent" iconLeft={<Icon/>}>Boost</Button>
```
Variants: primary (morado), accent (naranja), secondary, ghost, inverse. Sizes sm/md/lg. Reserve accent for one high-energy action per screen.
