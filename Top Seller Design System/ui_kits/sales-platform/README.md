# Top Seller — README

Sales-platform UI kit. Login → dashboard → pipeline, all
composed from the design-system primitives.

- `Icons.jsx` — thin geometric line icons (window.TSIcons)
- `AppShell.jsx` — Sidebar + Topbar (window.TSShell)
- `LoginScreen.jsx`, `DashboardScreen.jsx`, `PipelineScreen.jsx` — screens
- `index.html` — interactive orchestrator (sign in with the prefilled creds)

Note: Top Seller shipped no product code or screens. This kit is an
**invented but on-brand** sales/CRM surface that demonstrates the system.
Replace copy/data with real product content when available.
