# Top Seller — Design System

Brand + UI system for **Top Seller**. Morado-led, geometric, confident.
Consumers link one file: **`styles.css`** (tokens + fonts). Components are
bundled to `_ds_bundle.js` under the namespace `window.TopSellerDesignSystem_57ba3c`.

## What Top Seller is
**Top Seller is a real-estate marketing agency** (mercado mexicano,
español) that sells **systems, not services**. Its flagship offer is the
**Sistema Referente Inmobiliario™**, built on the proprietary
**Método Embudo Invertido™**.

- **Who it serves:** asesores / brokers / desarrolladores inmobiliarios who
  already sell but can't generate prospects predictably.
- **The promise:** *"Deja de ser un asesor invisible y conviértete en un
  referente en tu mercado en 30 días"* — prospectos constantes + control real
  de las ventas, sin depender de portales ni improvisar el marketing.
- **The enemy:** **"El Modelo Invisible"** — improvisar contenido, depender de
  portales, perder leads en WhatsApp, competir por precio.
- **The system delivers:** estrategia + contenido + edición + pauta +
  automatizaciones en Instagram + **CRM de ventas** + reportes, todo integrado.
- **Pricing:** valor percibido **$50,000 MXN**; inversión **$10,000 MXN/mes**
  (entrada estratégica). Exclusividad por zona — un asesor por mercado.
- **The three avatars:** *El Asesor Invisible* (Miguel → vende "visibilidad"),
  *El Competidor Oculto* (Carlos → vende "optimización"), *El Arquitecto del
  Mercado* (Alejandro → vende "dominio").

The fox mark fits perfectly: cunning, sharp, the asesor who stops being
invisible and starts being *seen*.

## CONTENT FUNDAMENTALS
How Top Seller copy reads (derived from the strategy docs).

- **Language:** **Spanish (México)** is the default for all customer-facing
  copy. English only for internal UI chrome if ever needed.
- **Voice:** directo, confrontacional, emocional. It names the pain out loud,
  reframes it as "no es tu culpa, es el sistema", then sells control. Short
  punchy lines, frequent line breaks, em-dash beats.
- **Person:** speaks to the asesor as **tú** ("Si eres buen asesor pero no te
  llegan prospectos…"). The agency is **"nosotros"** but understated — it
  *selects* clients, it doesn't beg ("Trabajamos con pocos, pero estratégico").
- **Reframe pattern (signature):** ❌ what they think → 👉 the real truth.
  e.g. *"No es que no sepas vender, es que no tienes un sistema que te haga
  visible."* / *"No es contenido. Es un sistema."*
- **Casing:** wordmark + display headers UPPERCASE (TOP SELLER); section
  eyebrows uppercase wide-tracked ("SISTEMA REFERENTE INMOBILIARIO").
- **Signature terms (use them):** Sistema, referente, invisible, control,
  visibilidad, posicionamiento, prospectos, "el Modelo Invisible", "Método
  Embudo Invertido™". Avoid agency words: *reels, contenido, diseño, redes*
  as the headline — always elevate to *sistema / control / visibilidad*.
- **Trademarks:** product/method/bonus names carry **™** (Sistema Referente
  Inmobiliario™, Método Embudo Invertido™, Protocolo de Conversión por DM™).
- **Numbers as proof:** anchor high ($50,000 MXN valor) then reveal low
  ($10,000 MXN). "hasta 10 prospectos mensuales", "en 30 días", "1 venta paga
  todo". Tabular MXN figures.
- **Emoji:** the **internal strategy docs** lean on 🔥👉✅❌⚔️ — these are
  working-doc shorthand, **NOT** the public brand voice. In customer-facing
  design, do **not** use emoji; carry energy through the fox mark, orange
  accent, bold Gilroy, and the ❌→👉 reframe rendered as typography/icons.

## VISUAL FOUNDATIONS

**Color.** Primary **Morado `#7060D8`**. Base **Negro `#081010`** + **Blanco**.
Single accent **Naranja `#F08048`**, reserved for one high-energy moment per
view (a hot badge, a primary CTA's sibling, an active tab underline). Full
tint/shade ramps in `tokens/colors.css`; semantic aliases (`--action-primary`,
`--surface-brand`, `--text-accent`, status colors) are what components read.
Imagery/illustration: the only "illustration" is the line-art fox mark, often
oversized and faded (8–22% opacity) as a background motif on dark panels.
No photography supplied; no gradients in the brand (flat fills only).

**Type.** One family, **Gilroy**. Display + all UI weight is **ExtraBold (800)**
— tight tracking (`-0.02em`), near-1.0 line-height, used for the wordmark feel.
Body/secondary text is **Light (300)**. Only those two weights are real files;
`tokens/fonts.css` maps 400/500→Light and 600/700/800→ExtraBold so you never
get faux-bold. Eyebrows: 11px ExtraBold, `0.14em` tracking, uppercase, orange.

**Spacing & layout.** 8-pt grid with a 4-pt half-step (`tokens/spacing.css`).
Dashboards use 28px page padding, 16px gutters between cards. Sidebar 248px.

**Radii.** Geometric/angular brand → **modest** radii: cards `14px`, controls
`10px`, inputs `10px`, chips/avatars pill. Nothing blobby.

**Borders.** Hairline `1px var(--border-subtle)` (ink-200) on light surfaces.
The `accent-edge` card adds a 3px orange top rule. Active tab = 3px orange
underline. Alerts use a 3px left bar in the tone color.

**Shadows.** Soft, low-contrast neutral elevation (`--shadow-xs…xl`). Primary
buttons + brand cards get a **purple-tinted** lift (`--shadow-brand-sm/md`);
accent buttons get an orange-tinted lift. No hard/long shadows.

**Motion.** Quick + confident, **no bounce**. `--ease-out` (cubic-bezier
.22,.61,.36,1), 120/180/280ms. Hover = darker fill (primary→purple-600) +
slightly stronger shadow. Press = `translateY(1px) scale(.99)` on buttons,
`scale(.94)` on icon buttons. Switch/progress slide on `--ease-out`.

**Transparency / blur.** Used sparingly — faded fox watermark on dark; nav
badge pills use `rgba(255,255,255,.22)` on the active morado item. No glassmorphism.

**Cards.** White surface, hairline border, `--shadow-sm`, 14px radius.
Variants: `brand` (morado, light text), `inverse` (black), `accent-edge`
(orange top rule). `interactive` adds a 2px hover lift.

## ICONOGRAPHY
- The brand mark is a **single-stroke geometric line drawing** (a faceted fox
  head). UI iconography matches it: **thin (1.75) line icons, round caps,
  geometric**, no fills.
- No icon font or SVG set was provided, so the kit ships a small hand-built
  line set in `ui_kits/sales-platform/Icons.jsx` (`window.TSIcons`) drawn to
  that spec. **Recommended substitute / extension:** **Lucide**
  (lucide.dev — thin geometric line, same stroke feel) when a broader set is
  needed. Flagged: this is a substitution, not an official Top Seller icon set.
- **Emoji:** never. **Unicode glyphs:** only ▲ ▼ — for stat deltas.
- Logos live in `assets/logos/` — use `<Logo>` (wordmark/mark, 4 colorways).
